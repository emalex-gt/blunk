# Blunk Orange + Graphite theme

Global visual migration applied to the uploaded frontend bundle.

## Brand roles
- Primary: `#F97316` (orange)
- Primary hover: `#EA580C`
- Accent: `#F59E0B` (amber)
- Graphite: `#0F172A`
- Canvas: `#F3F4F6`
- Surface: `#FFFFFF`
- Muted: `#64748B`
- Info: `#0284C7`
- Success: `#16A34A`
- Warning: `#D97706`
- Danger: `#DC2626`

## Scope
- All previous Indigo brand utilities migrated to Orange.
- Violet brand utilities migrated to Amber.
- Success / warning / danger semantics preserved.
- Informational Toast remains Sky blue.
- Authenticated and Super Admin navigation use graphite shells with orange active states.
- POS retains the stronger graphite cart header and orange→amber CTA treatment.
- Semantic CSS variables and Tailwind `blunk.*` tokens added for future refactors.

No application logic was intentionally changed.
